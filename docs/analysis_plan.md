# Analysis Plan

## 프로젝트 개요

본 프로젝트는 초등학교 안전사고 데이터에서 반복적으로 함께 발생하는 위험요인을 Apriori 연관규칙 분석으로 식별하고, 보상 데이터의 피해 규모를 결합하여 예방관리 우선순위(PPS)를 제안한다.

## 연구 질문

1. 초등학교 안전사고는 언제, 어디서, 어떤 활동 중 많이 발생하는가?
2. 장소·원본 사고시간·사고형태·활동·학년은 어떤 조합으로 반복 발생하는가?
3. 사고 빈도, 연관 강도, 피해 규모를 함께 고려할 때 우선 관리할 위험상황은 무엇인가?

## 데이터 활용 전략

- 사고 데이터는 전처리, EDA, 통계분석, Apriori 분석, Frequency 산출에 사용한다.
- 보상 데이터는 사고 데이터와 직접 결합하지 않고 Severity 산출에 사용한다.
- 분석 대상은 초등학교 사고 기록이며, 의미 있는 결측은 `미상` 범주로 유지한다.

## 분석 흐름

```text
데이터 전처리
↓
EDA
↓
카이제곱 검정과 Cramér's V
↓
Apriori 연관규칙 분석
↓
보상데이터 분석
↓
PPS 계산
↓
시각화 및 정책 제안
```

## EDA와 통계분석

EDA에서는 연도, 월, 학년, 성별, 요일, 원본 사고시간, 장소, 사고형태, 활동, 부위의 분포와 교차표를 생성한다. 통계분석은 장소×사고형태, 장소×활동, 활동×사고형태, 학년×장소, 원본 사고시간×장소를 대상으로 카이제곱 검정과 Cramér's V를 수행한다.

## Apriori 연관규칙 분석

각 사고 기록은 다음 항목을 가진 하나의 거래로 변환한다.

- `place=<사고장소>`
- `activity_period=<원본 사고시간>`
- `accident_type=<사고형태>`
- `activity=<사고당시활동>`
- `grade=<학년>`

빈발항목집합은 최소 support 1% 이상을 기준으로 추출한다. 연관규칙은 confidence 30% 이상, lift 1.0 이상을 기준으로 정렬하며, 임계값은 설정 파일에서 관리한다.

## PPS

PPS는 Frequency, Association, Severity를 Min-Max 정규화한 뒤 가중합으로 계산한다.

```text
PPS = 0.40 × Frequency + 0.30 × Association + 0.30 × Severity
```

Association은 Apriori 규칙의 confidence와 lift를 바탕으로 산출한다. 가중치 변화에 따른 순위 안정성은 후속 민감도 분석에서 검토한다.
