# 변수사전

| 변수명 | 설명 | 유형 | 출처 | 처리 원칙 |
|---|---|---|---|---|
| region | 학교 소재 시도 | 범주형 | 사고원자료 | 표준 시도코드로 매핑 |
| school_level | 학교급 | 범주형 | 사고원자료 | 분류 변경 여부 점검 |
| incident_year_month | 사고발생 연월 | 날짜 | 사고원자료 | 접수연도와 분리 |
| incident_time | 사고발생 시각 | 시간 | 사고원자료 | 시간대 파생변수 생성 |
| incident_place | 사고장소 | 범주형 | 사고원자료 | 상위 장소군 병행 |
| incident_type | 사고형태 | 범주형 | 사고원자료 | 2023 브리지 매핑 |
| activity | 사고당시활동 | 범주형 | 사고원자료 | 활동군·실외여부 파생 |
| student_count | 학생 수 | 수치형 | 학교알리미 | 연도별 분모 |
| student_hours | 학생 노출시간 | 수치형 | 시간표·출결 | 사고율 offset |
| total_compensation | 총 보상액 | 수치형 | 보상원자료 | 로그·상위값 민감도 분석 |
| pps | 예방관리 우선순위 점수 | 수치형 | 산출 | 구성요소와 버전 기록 |

새 변수는 변수명, 정의, 산식, 시점, 출처, 개인정보 등급을 추가한 뒤 사용한다.
