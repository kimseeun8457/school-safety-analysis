# 프로젝트 파이프라인

## 목적

사고 예측을 학교의 예방행동 우선순위로 전환하는 P4-SAFE 파이프라인을 정의한다.

## 단계

1. **Ingest**: 사고·보상·외부데이터를 원본 그대로 수집하고 출처·수집일·이용조건을 기록한다.
2. **Audit**: 중복, 결측, 날짜, 범주, 2023년 분류체계 변경을 점검한다.
3. **Standardise**: 분석용 상위분류와 원본 범주 간 매핑 테이블을 유지한다.
4. **Build panel**: 학교(또는 지역)·학교급·주·위험상황 단위의 노출 보정 패널을 만든다.
5. **Model**: 빈도·심각도·반복성을 시간 기준으로 예측한다.
6. **Prioritise**: PPS로 예방가능 손실 대비 개입비용이 큰 상황을 선정한다.
7. **Act**: 학교별 Top 3 예방관리 행동을 제시한다.
8. **Prove**: 개입 전후 사고율·손실 변화를 준실험 설계로 검증한다.

## 산출물

- 정제 데이터셋 및 데이터 품질 리포트
- 위험상황 프로파일
- 예측·보정·공정성 평가표
- PPS 우선순위표와 정책 브리프
- 재현 가능한 코드·환경·실험 로그
